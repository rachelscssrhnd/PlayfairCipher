Cara kerja Playfair (langkah demi langkah) 
<h3>Cara kerja Playfair</h3><div class="book"><pre>1. Grid 5x5: tulis kunci tanpa huruf ganda, lanjutkan dengan sisa alfabet. I dan J satu sel.
   Kunci MISTERI:
   M I S T E
   R A B C D
   F G H K L
   N O P Q U
   V W X Y Z

2. Siapkan teks: buang non-huruf, J jadi I, pecah jadi pasangan.
   Huruf kembar dalam satu pasangan disisipi X. Jumlah ganjil ditambah X di akhir.
   LAMPU -> LA MP UX

3. Enkripsi tiap pasangan:
   baris sama : ambil huruf di kanan (ME -> IM)
   kolom sama : ambil huruf di bawah (SH -> BP)
   persegi    : tukar kolom (LA -> GD)
   LAMPU -> GDSNPZ

4. Dekripsi: baris ke kiri, kolom ke atas, persegi sama seperti enkripsi.
   X sisipan dibuang manual, program hanya menebak.

Playfair adalah sandi klasik (1854) dan mudah dipecahkan komputer.
Dipakai untuk belajar, bukan untuk melindungi data nyata.</pre></div>
